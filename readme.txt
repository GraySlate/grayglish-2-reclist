Hello!  This folder contains all resources for recording and configuring GrayGlish 2.0 voicebanks.

GrayGlish 2.0 is a custom X-Sampa English reclist.  All GraySlate English UTAUs use GrayGlish 1.0 or 2.0.

Resources included:

- GrayGlish 2.0 Development Guide PDF
- Full GrayGlish reclist
- Full OREMO GrayGlish reclist
- X-Sampa phoneme pronunciation guide
- Full base oto
- Full suffixed base oto
- Sample recording examples
- Base vLabeler projects (G3 and non-suffixed)
- IroIro2 Replace lists (VCCV/ARPAsing to GrayGlish)
- Replacement en-xampa.yaml file for OU's X-Sampa EN phonemizer
- Sample UST/USTx:  Take Me To Church (Hozier)
